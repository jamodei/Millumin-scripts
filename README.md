# Millumin-scripts

Code to help out with projects and workflow issues, ideas, and sketches for [Millumin](https://www.millumin.com/v5/index.php#) in the context of live performance.

## Scripts

| Folder | What it does |
| --- | --- |
| [`eos-column-gate`](eos-column-gate/) | Lets an ETC Eos console launch Millumin columns over OSC, and ignores cues that have no matching column so playback doesn't stop. |
